## 验收

- 后三章使用独立高质量实装位图：每章一张全景、一张透明角色部件图集和一张透明地形图集，共九套资源、36 个透明部件；保留原始文件与提示词。
- 后三章敌群互不借用；不同移动、预警、投射物与对策。禁止用换色代表新敌人。
- 地图几何与视觉来自同一状态，断桥确实可坠落，电梯确实承载，传送带确实运输，活体屏障确实阻挡与可破坏。
- Boss 可见部件与命中部件一致，打到空隙不吞子弹，部件被破坏会改变战斗；普攻、所有武器、无人机和炸弹均有可行对策。
- 战斗与关卡截图覆盖中文、英文和常用窗口尺寸，检查 UI 与地图遮挡。
- 完整战役推进、暂停、升级、复活、检查点、最终结算通过回归；清楚记录 headless 验证与真实 IDE 验证的区别。
- 只有经过整合与质量检查的本地完整插件包可以标为完成。
