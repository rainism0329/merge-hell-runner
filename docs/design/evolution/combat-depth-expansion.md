# 操作、难度与探索深化方案 · 2026-09-15

状态：已按用户确认进入实现，核心交付为八向操作、三档难度、五章探索与跳跃路线、四角色和兼容旧档的段间保存。实际数值、产物和验收证据见 [实现与验收记录](combat-depth-validation.md)。下面保留最初设计依据，不能把候选项全部视为已经上线。

本轮范围说明：定点瞄准使用 V，提供 F1 双语操作手册；练习复用现有无敌练习和 Boss 练习入口。独立训练地图、自定义改键和敌人图鉴尚未实现。工程师具有独立厚眼镜、疲惫表情和工牌造型；咖啡杯放在隐藏办公室，未增加手持咖啡待机动画。自动实战用于验证可通行与战斗结果，不能替代用户在 IDE 中的手感评价。

## 当前问题的代码依据

- `EntityType` 中多种开局敌人仍只有1点生命，而六种武器的初始单发伤害已为12–80，耐久尺度不一致。
- 第二至第五章的 `Boss` 构造会把关卡提供的血量除以2，实际核心血量为1750/2500/3250/4000。应统一为显式实际血量配置，避免调参时再隐式折算。
- 后三章大多单只触发敌人；战斗区每波常为1–2只，清完后才继续下一波。专属敌人的血量和攻击周期不会随当前难度变量一起增长。
- 普通Boss身体接触伤害为5，受伤保护为60模拟步。需要实测“持续贴脸承受小伤害，借无敌躲过大攻击”的利用方式。
- 炸弹同时清兵、清弹、伤核心与部件，并保留击杀分数、经验和超频收益；分数又可补充炸弹。需要平衡这组收益及连续使用节奏。
- 当前平台与危险区已经有真实物理，但关卡触发按横坐标组织；第二至第五章的Boss门统一在7600，世界宽8600。主路径的跳跃、折返和探索约束仍较弱。
- `Projectile` 支持二维速度和旋转显示，`FireRequest`、玩家枪口和角色姿态目前只支持左右朝向。弹丸旋转后仍用固定宽高命中框，扩展八向时须同步修正。

## 1. 操作基础

优先完整实现地面下蹲、蹲射、八向射击。保留左右移动、空格跳跃、C射击的现有操作：

| 输入 | 行为 |
| --- | --- |
| 上 | 向上瞄准 |
| 上＋左/右 | 向对应斜上方瞄准并移动 |
| 地面下 | 下蹲，射击时使用降低后的水平枪口 |
| 空中下 | 向下瞄准 |
| 空中下＋左/右 | 向对应斜下方瞄准 |
| 独立定点瞄准键 | 暂停水平移动，允许站定选择方向；支持改键 |

空中下键先承担向下瞄准，地面下蹲与空中瞄准使用清晰的不同姿态。斜向弹速归一化；六种武器的散射、火焰、激光、后坐力与枪口火光都围绕同一瞄准方向计算。延续前进射击的速度继承，避免重新出现跑动时射程显短的问题。

下蹲缩小实际身体碰撞框，脚底不跳动，站起检查头顶空间。需要完整实体顶棚碰撞后，再设计低矮通道。修正竖射击退、旋转弹丸命中框和扫掠检测；暂停、菜单、失焦和升级界面不得残留瞄准输入。

## 2. 难度与战斗配合

提供休闲、标准、挑战三档，标准作为默认调校目标，现有练习功能保留。难度写入本局和检查点，排行榜按难度区分。旧记录与旧存档需要明确迁移规则。

首轮调校候选：

- 保留少量一击击杀的轻兵；需要执行招式的普通单位约30–50生命，重装约100–160。根据武器命中数和单位职责进一步分配。
- 后三章部分精英生命增加20%–35%；Boss以当前实际血量增加40%–60%为首轮测试范围，目标是稳定经历2–3轮核心机制。
- 后期敌人的攻击后停顿缩短15%–25%，保留清晰预警。由远程牵制、近战冲锋、空中骚扰形成错峰配合。
- 普通Boss接触伤害试调15–20并轻推开玩家；明确保留可安全近身输出的位置和窗口。
- 炸弹加入约0.8–1.2秒独立冷却，保留清弹救场，控制核心伤害和资源回流。不能通过长按或快速按键连续跳过整段战斗。
- 部分回血、护盾与炸弹移到高台或支路，形成风险与奖励；主路仍有可预期补给。普通模式保留合理复活保障。

Boss增加阶段组合，而非每阶段只重复单个招式：吊装首领上下交替压制与双爪协同；攻城兽用冲锋改变前后关系，再接熔弹落点；异星首领结合器官、孵化与移动心脏。所有组合应有可达安全区，不能产生无解伤害。

平衡在新操作完成后进行，因为上射、下射、蹲射会明显提高玩家处理敌人的能力。分别验证基础武器与成型构筑；自动探针用于发现卡关、无解攻击和资源漏洞，人工实玩决定是否有趣、是否紧张。

## 3. 五章内容与路线

每章先增加约25%–40%的有效内容，按遭遇和探索体验验收长度。以短段落组织路线，提供段间保存，兼顾工作间隙游玩。

| 章节 | 新路线主题 | 战斗与探索内容 |
| --- | --- | --- |
| 第一章 | 地面街区与屋顶小路、低矮维修通道 | 基础八向射击教学；藏在旧办公室的工牌与留言 |
| 第二章 | 排水设施上下层、阀门改变水位 | 选择干燥高路或危险湿路；侧向检修间和隐藏补给 |
| 第三章 | 升降井、断桥、多层吊装通道 | 必须跳跃到达的落点；控制设施改变可行路线；废弃控制室 |
| 第四章 | 高低输送带、升降货台与循环热闸 | 冷却创造通行窗口；运输机械遭遇；偏离主路的冷却工坊 |
| 第五章 | 活体通道、上下巢室与收缩膜门 | 上下方向敌人协同；破坏器官开路；隐蔽培养舱 |

每章加入一个短的特殊遭遇或精英事件，少量自愿探索的岔路和至少一个有线索的秘密。奖励优先采用角色解锁、外观、记录和有限补给，避免探索叠加过量永久伤害。

实现上将散落的固定坐标组织为段落定义，包含几何、镜头边界、入口出口、遭遇、事件与奖励状态。支持段内折返和上下移动，避免重复刷敌/刷奖励；检查点记录段落和关键事件，同时兼容现有章节入口存档。所有角色、基础武器都能走通主线。

## 4. 角色选择

先做三个常规角色和一个隐藏角色的独立造型与完整动作：维修机器人、轻型勘探员、重装安保，以及疲惫值班工程师。

工程师有厚眼镜、黑眼圈、松垮工牌、低头站姿和咖啡杯待机细节。通过有环境线索的隐藏维修室解锁；让角色彩蛋与地图探索相连。不同角色不能只换颜色。

角色身份独立于武器，可自由组合；统一设计站立、跑跳、蹲姿、八向持枪、受击和死亡。菜单提供角色预览、已解锁状态和简短介绍。继续游戏使用存档角色，旧存档默认维修机器人。

先保证外观、选择与存档闭环，再加入少量有代价的差异，例如敏捷换生命、护甲换速度、工程师擅长设施维护。没有角色专属的主线必需能力，也不让隐藏角色天然成为最强选择。

## 5. 配套体验

- 改键与操作图示；训练区可单独练蹲射、上下瞄准、跳跃射击。
- 受伤来源反馈、敌人/首领图鉴；通过清晰动作和提示让失败原因可理解。
- 段落进度、秘密收集记录和自动保存提示；隐藏内容有环境暗示。
- 难度和角色切换不影响已有检查点，死亡与继续逻辑一致。
- 持续保持中英双语统一、默认静音、清晰的炸弹与技能状态、小窗口可读性和受控渲染成本。

## 实施顺序与验收

1. 统一输入、瞄准、姿态与碰撞；六种武器支持八向射击，地面蹲射可用。
2. 建立集中难度配置，调整五章敌群、Boss、补给及炸弹收益，完成基础/成长两种配置验证。
3. 将五章地图扩展为有跳跃约束、立体遭遇、支路与段间保存的内容。
4. 完成角色选择、独立动作、存档兼容和探索彩蛋解锁。
5. 全战役回归、两种语言/常用窗口视觉验收、真实输入探针及人工难度调校。

优先级最高的是操作和遭遇设计。它们决定新增血量、地图长度、角色能力能否转化为更好的游戏体验。
