# 操作、难度、角色与探索升级验收 · 2026-09-15

本轮实现了八向射击与蹲射、三档难度、五章路线扩展、独立角色选择、工程师彩蛋和安全段落保存。生产代码、素材、双语文案和可安装 ZIP 一起交付。本记录区分自动输入结果、渲染截图和人工实玩；不把自动通关等同于“手感已完美”。

## 已实现

| 项目 | 实际行为 |
| --- | --- |
| 八向射击 | 六种武器的散射、蓄力光束、枪口、持枪方向和扫掠碰撞共同旋转；移动速度只继承一次 |
| 下蹲 | 地面下键降低伤害框、枪口与姿态；低通道必须蹲行，头顶有挡板时不能强行站起 |
| 空中操作 | 上、下与左右组合决定射击方向；V 保持原地瞄准，空格保留二段跳 |
| 角色 | Y 切换维修机器人、轻型勘探员、重装安保、夜班工程师；Z 独立选择武器 |
| 角色差异 | 勘探员速度 +13%、承伤 +10%；安保速度 -13%、承伤 -15%；工程师速度 -4%、每个设施交互额外修复 8 HP |
| 工程师彩蛋 | 正常战役进入第一章旧办公室，按 E 阅读工牌留言并永久解锁；厚眼镜、疲惫表情、工牌和服装使用独立素材；练习可预览 |
| 难度 | D 选择休闲／标准／挑战，默认标准；生命、承伤和出招恢复统一应用，排行榜分档 |
| 炸弹 | 保持小图标和数量显示；约 1 秒冷却，有限范围伤害，降低清兵经验和分数，不再用炸弹击杀续超频 |
| 关卡 | 真实实体挡板、上下平台、蹲行通道；每章两个必需设施、一个可选秘密，设施触发专属遭遇和叙事 |
| 继续游戏 | 安全段落记录生命、弹药、炸弹、构筑、角色、难度、已访问设施和已破坏结构；菜单区分章节入口与安全段落 |
| IDE 体验 | 默认静音；中文／英文完整配对；F1 操作手册会暂停战斗；暂停和失焦清除瞄准、射击与交互输入 |

工程师不会直接提高武器伤害；所有角色能使用所有武器。独立训练地图、自定义改键和敌人图鉴仍是设计候选，本轮没有将这些候选标成已完成。

| 地热铸造厂 | 冷却工坊、货运高台、热管下方蹲行、追加输送带与排气台 | 4900 |

第二至第五章首领门从 7600 延长到 9900，世界宽度从 8600 到 10900；第一章编排时间从约 260 秒增加到约 330 秒。真实游玩时长还受探索、战斗和暂停影响。

普通杂兵的生产血量统一到武器伤害尺度：BUG 18、CONFLICT 38、LOCK 48、CRASH 32、FIREWALL 120、LEAK 42、TECHDEBT 145；章节专属敌人以原血量的 1.27 倍为标准。修正 Boss 构造器曾隐式将血量折半的问题。标准档恢复周期缩短，后期 Boss 第二、三阶段交替使用更紧凑的组合，但保留预警、破甲窗口和重建时间。接触伤害提高并加入有边界的击退。

休闲档生命／承伤／恢复时间倍率为 0.72／0.65／1.25；挑战档为 1.28／1.20／0.80。旧检查点未指定角色、难度时使用维修机器人和标准档。旧总榜数据保留在存档中，新成绩使用分难度榜。

## 验证与证据

生产路径的全量 Gradle 测试共 **728 项**，均通过；额外加强的检查点测试通过 IntelliJ 的实际 XML 序列化器读写五章段落、角色解锁与分难度榜。覆盖六武器八向发射、光束扫掠碰撞、角色通行、蹲行净空、实际按键、炸弹冷却、存档兼容与世界状态恢复。测试曾发现并修正远端断桥仍使用旧世界宽度、无穷远碰撞误吞子弹等问题。最终小窗口预览还发现新手册标签与旧底栏共用翻译键，已分离命名并加入重复键回归检查；两种语言各有 805 个配对键。

自动实战从确定的章节／种子／入口配置开始，之后使用真实 ActionMap 按下和松开边沿，驱动生产移动、射击、跳跃、近战、炸弹、升级和复活。没有通过测试接口补血、传送、删敌、强制 Boss 受伤或开启 Lab。成型入口额外配置八个合法升级；基础入口为未升级提交炮。Boss 探针在门前使用已完成路线的明确夹具，路线探针则实际完成所需设施。

| 章节 | 基础路线步数／结束生命条数 | 成型路线步数／结束生命条数 | 基础 Boss 步数／剩余 HP | 成型 Boss 步数／剩余 HP |
| --- | --- | --- | --- | --- |
| 3 | 6732／2 | 4923／3 | 5538／46 | 3333／100 |
| 4 | 11269／2 | 5427／3 | 2945／10 | 2247／10 |
| 5 | 6178／1 | 4802／3 | 3800／28 | 4677／7 |

全部六个最终路线探针到达 Boss，六个 Boss 探针击败 Boss。一步为 16 ms 模拟步；这些不是墙钟计时。成长配置改变无人机、弹射、复活和自动玩家的决策，不能用单个种子断言它必定比基础配置更快。

保留了第四章基础路线的两次 STEP_LIMIT 记录：旧探针在盖板上反复跳跃，持续瞄准被实体掩体遮住的地面敌人。加入识别遮挡后移动换位、地面蹲行后，同种子、同资源、同 14000 步上限通过；没有为此降低关卡难度或删除实体。

截图来自实际 Swing 绘制，覆盖中英菜单、四角色、操作手册以及五章新增地形的 960×600 与 600×400 窗口。截图夹具设置章节／相机并清除敌人，以检查构图，不能作为无作弊通关证据。最终烟雾检查直接从 ZIP 内的 instrumented JAR 加载生产类与资源。

第一、二章本轮通过既有战役回归和新角色通行／设施测试；没有另外声称完成五章连续人工通关。原生 IDE 手感、系统快捷键冲突和真实显示帧率仍需在安装后的 IDE 中体验。

## 性能

五章 × 普通／上限负载 × 三种尺寸，共 30 个独立场景；每个预热 750 ms、采样 1750 ms。实际执行 GameLoop → GamePanel → FrameMailbox 发布，再由 EDT 绘制。普通负载配置 6 敌人、32 玩家弹、12 敌弹、120 粒子；压力配置为 40／320／180／1200。构造合成负载的时间不计入采样。

| 窗口 | 普通场景模拟＋发布 P95 | 压力场景模拟＋发布 P95 | EDT 绘制 P95 范围 |
| --- | --- | --- | --- |
| 600×400 | 6.21–8.54 ms | 12.59–14.95 ms | 2.71–2.87 ms |
| 960×600 | 6.04–8.84 ms | 12.91–21.45 ms | 1.58–2.25 ms |
| 1280×800 | 5.92–8.54 ms | 12.30–14.52 ms | 10.38–11.17 ms |

第一章 960 压力样本存在 82.17 ms 峰值，不能声称压力下恒定 60 FPS；大窗口软件缩放也比 IDE 小窗口昂贵。这是 headless 调用耗时，不是显示 FPS。30 个窗口关闭后所有帧邮箱保留缓冲数均为 0，没有残留游戏调度线程；显式 GC 后堆使用约 118 MiB，包含共享章节素材缓存。

## 素材与复现

本轮使用 **内置 imagegen** 生成三套独立角色拆件和一套八件环境素材，保留原生 RGBA。没有调用付费 API／CLI fallback。确定性脚本仅裁切、整理图集、填写关节锚点，没有用平面矢量图冒充最终插画。

- 角色源图、提示词、哈希：[sources/characters](sources/characters/manifest.json)。每个角色旁的 `*-prompt.txt` 保存完整最终提示词。
- 环境源图、完整提示词：[route-props-prompt.txt](sources/routes/route-props-prompt.txt)；[manifest.json](sources/routes/manifest.json)。
- 生产图集位于 `src/main/resources/game/art/` 的 `scout`、`warden`、`engineer`、`route-props` PNG 与 properties 文件。
- 打包脚本：`scripts/art/export_characters.py`、`scripts/art/export_route_props.py`。
- 原始验收输出：`build/depth/`；归档证据：[docs/qa/data/2026-09-15-combat-depth](../../qa/data/2026-09-15-combat-depth/index.md)。

构建使用本机 JDK 17 和已缓存 IDEA 2023.2.2 SDK：`gradlew.bat build buildPlugin verifyPlugin --offline --no-daemon --console=plain --init-script build/singularity-verification/isolated-sandbox.init.gradle`。`verifyPlugin` 为本地包结构／元数据检查，没有冒充全版本 Plugin Verifier 兼容矩阵或 Marketplace 发布。

安装包与最终 SHA-256 记录在归档证据的 `package.json`。可从 IDE 的 Plugins → Install Plugin from Disk 选择 `build/distributions/merge-hell-runner-1.0.0.zip`，按 IDE 提示重新启动。
