## 已接入生产路径

- 工业服务器城市背景、金属地面、紧凑 HUD、菜单、升级卡片和设置页。渲染资源预加载，缺资源有诊断和回退。城市目前是共享样板，不是五套完成的世界素材。
- 主角和敌人姿态由模拟时间驱动；姿态记录只包含值。支持跑跳、落地、冲刺、射击后坐、近战、受击与死亡的分件渲染路径，外观尺寸不作为碰撞框。主角/Bug/TechDebt/Legacy 图集仍待真实透明导出，当前实际截图使用矢量回退，不能视为角色美术完成。
- 三个预分配帧缓冲由 `FrameMailbox` 管理，模拟线程绘制完整帧，EDT 只读取已经发布的帧。不会向 EDT 暴露可变 Player、敌人或像素数组。它是完整画面发布方案，尚不等于计划中的全量语义 `RenderSnapshot` 或完整会话拆分。
- 六把起始武器均可通过 Z 选择，各自的升级、核心、进化和状态效果已接通；升级候选耗尽时提供即时补给。近战、冲刺、热量、蓄力等使用实际发射序列决定音画反馈。
- 六条组合：Dash Cache 冲刺后下一次真实齐射强化；Force Push 将敌人击退到真实平台侧面时爆破；标记优先引导无人机；每次近战最多反弹三枚普通弹，每枚补 12 点 SUDO；灼烧击杀留下残留区域；暴击延长连击窗口。链条具有来源、根事件、深度与目标/区域上限。屏幕边缘和装饰背景不作为可撞击墙壁。
- 程序生成 PCM 短音效区分六武器，另含命中、受伤、冲刺、升级、SUDO 与 Boss 阶段。缓存样本、8 声部、事件限流、过期丢弃和设备失败降级；模拟线程及 EDT 不等待设备。没有完成五世界动态配乐，真实设备听感尚未试听。
- Schema 2 关卡入口检查点恢复构筑、进化、HP、生命、弹药、资源、XP、SUDO、分数、战斗与升级随机状态。旧不完整 ActiveRun 备份并保留长期数据，不伪造恢复。窗口所有权避免互相覆盖进度。
- 新局、跨关、继续三条路径从 run seed 与关卡派生独立地形、敌人、生成、Boss、掉落及装饰随机流。敌人不再共享 static Random 或使用墙钟推进运动。视觉随机不改变掉落结果。检查点仍只在关卡入口保存，不能解释为任意战斗帧回放。
- O 在菜单或暂停页打开设置，方向键选择/调整、Enter 切换、Esc 返回；M 快捷静音。震屏、CRT、闪光、粒子显示、音量、静音、自动射击、高对比度立即应用并保存。设置键不会泄漏为开火、跳跃或恢复命令。
- 显示宽度小于 768 像素时切换紧凑布局；关键 HUD 字体放大并省略次要数据。尺寸请求与可取消的用户输入分开，失焦不会丢失尚未应用的尺寸配置。
- 修复跨关恢复点残留、初始恢复点复活帧陷入地面、暂停/升级时 Boss 消失或浮在遮罩上、Boss 入场横幅遮挡节点、旧开火序列产生假枪口闪光等集成问题。

## 如何体验当前版本

- Space/Enter 开始；Z 在菜单选择六把起始武器。
- 左右移动、Space 二段跳、C 射击、X 近战、Shift 冲刺、B 炸弹。
- P/Esc 暂停；暂停后 Q 返回菜单，R 从最近关卡入口继续。中途退出不保存当前战斗帧。
- O 设置；M 静音。小窗口自动使用紧凑 HUD。
- T/F12 打开 Lab 后本局永久不计排名，关闭 Lab 不会将这局重新变成正式局。

## 当前验证

正式原始基线为 160 项测试。最终集成为 **295 项测试 / 51 个套件，0 失败、0 错误、0 跳过**；`test/build/buildPlugin/verifyPlugin` 全部通过。编译前后 160 个源码/资源文件哈希一致，清单 SHA-256 为 `59fdb8942b69a69cdf2b13995ca2d1d27eb18189c2bbf9b958093dce6c0b4bba`。日志为 `.gradle/verification-logs/20260911-000035-228.log`，耗时 54 秒；安装包校验见 [Gradle 记录](2026-09-10-gradle-recovery.md)。

中途 257 项复验的失败是动画测试在首次落地时错误断言 RUN，已先推进到落地过渡结束，再检查暂停姿态不变。294 项复验则发现真实问题：过量致命伤害将 HP 扣至负数，复活固定加 100 可能仍为 0。已修正伤害/治疗的生命值边界与满血复活，并保留该主流程回归及新增溢出边界测试。

专项证据覆盖声音缓存/混音、帧发布跨线程边界、旧 XML 与复制隔离、升级卡池、六武器与连锁上限、关卡种子重建、真实 ActionMap 主流程。正式全套结果优先于早期专项数字。

实际视觉预览通过生产 `GamePanel → GameLoop → renderer → FrameMailbox → EDT paint` 输出。包括菜单、战斗、升级、设置、暂停、Legacy Boss 和 Boss 暂停，共 7 场景，分别检查 600×400、960×600、1280×800；另有 96 个连续 16 ms 动作帧。响应尺寸改变时真实推进一次回调以应用布局；连续动作序列没有额外尺寸回调。输出目录 `build/visual-preview/`，使用受控 LAB 场景，不是正常通关证据或概念图。

本批全程 headless、禁用声音设备，没有恢复此前被用户 Esc 停止的桌面控制。未把这些截图当作原生 IDE 安装与焦点生命周期验收。
