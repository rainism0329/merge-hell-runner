## 使用方式与行为

主菜单或暂停时按 **O** 打开设置，选择第九项 **界面语言 / LANGUAGE**，用左右键选择 **简体中文 / English**，也可按 Enter 切换。修改立即生效并自动保存。旧存档首次按系统语言选择：中文系统默认简体中文，其他系统默认英文。之后保留用户明确选择的语言。

当前剧情、已有日志和仍在显示的浮字都在绘制时读取语言，因此无需重开关卡。暂停时切换语言不会推进世界、改变生命值、分数或节点状态。独立游戏窗口的绘制语言相互隔离。按键标识、编程语法和 IDE 插件名保持可识别的原文，它们不承担另一种语言的游戏说明。

两份 UTF-8 资源各包含 505 条文字。中文统一了生命、超频、回收站、首领和进化等术语；使用系统内已安装的中文无衬线字体，并保留其他平台的字体回退。设置页调整为九行；菜单按钮说明缩短；升级卡增加文字区域，支持英文按词换行和中文按字换行。

## 检查与修复

- 资源键与参数占位符保持一致；覆盖全部武器、升级、无人机各级说明和动态伤害/时间。
- 真正通过面板按键切换语言、保存设置，并比较前后世界 tick、节点快照、生命和分数；两个面板交错绘制不串语言。
- 使用 IntelliJ 的实际 XML 序列化验证双语保存、缺失/无效语言回退、显式语言不受以后系统语言改变影响，以及其他进度保留。
- 更新旧测试中硬编码的中文原始消息断言为控制器的英文规范消息；玩法断言保留，新增独立显示语言断言。
- 检查每张升级的标题、描述和效果在两种字体下的宽度/行数；暂停设置与无敌关闭状态保持一致。
- 实际截图审查发现 `[ L ]` 被过宽的等级模板误识别。已限制等级、单位及相关槽位为数值，并加入全部常用按键标记保持不变的回归断言。
- 异常页的直接发布原先不经过普通帧入口，已补充独立语言作用域；内部错误信息继续保留，玩家看到一致语言的恢复说明。

`LanguagePreview` 导出 60 张实际面板图，覆盖 15 种场景 × 2 种语言 × 2 种尺寸（960×600、600×400）。场景包括主菜单、设置、第一关战斗与 Legacy、第二关选择/泄漏/首领、后三关首领、升级、暂停、通关、失败及异常页。等级入口、位置、通关和异常状态包含明确的验证前置条件；这些是 headless 面板证据，不是正常五关通关或原生 IDE 真人试玩。

最终绘制文字另存 `build/language-preview/displayed-text.txt`，用 `scripts/verify-languages.py` 自动检查缺失场景与语言混用，**60 个场景全部通过**。最终正式编译代码重新导出了全部画面；[保留的 14 张代表图与完整文字](images/2026-09-11-bilingual/README.md)覆盖双语菜单、设置、升级、Heap 选择/首领、Legacy、结算和异常页。语言架构和后续新增文字规范见[本地化约定](../design/evolution/localization.md)。
