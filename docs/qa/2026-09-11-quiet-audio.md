# 默认静音、场景氛围与 Boss 背景音

2026-09-11。游戏用于 IDE 工作间隙，本批将默认声音策略改为静音，并在已有 16 种战斗音效上加入五世界氛围与 Boss 战背景音。

## 操作与默认行为

- **M** 开启/关闭全部声音，保存用户明确选择。新配置和没有明确静音字段的旧 XML 默认静音；不会每次打开都覆盖已经保存的手动选择。
- 主菜单或暂停时按 **O**，分别调整主音量和背景音量。默认主音量 35%、背景音量 20%；背景音量是主音量下的相对比例，设为 0 可以只听战斗音效。
- 主菜单保持安静，进入战斗后才播放。暂停、升级选择、失败、关末、胜利与异常页都会暂停声音。
- 切回编辑器或隐藏游戏立即请求静音、清除待播旧音效；重新获得焦点保持暂停，按 P 恢复。关闭面板会释放音频服务。
- 默认静音启动既不生成背景样本，也不创建/打开声音设备。第一次明确开启且进入游戏时，由后台线程准备音频。设备不可用时游戏继续运行。

五个场景分别使用工业机械低鸣、内存区低频氛围、蓝图城的轻电子音、内核的紧张短句、奇点的低音旋律；Boss 使用更密的脉冲。均为本项目确定性合成的原创短循环，无外部下载或运行时依赖。背景转场为 600ms 交叉淡化；静音/暂停采用 40ms 软件淡出并清空设备队列。实际扬声器停止延迟仍取决于设备，尚未做原生设备测量。

背景使用独立混音层，保留已有 8 个战斗音效声部及事件限流；不会挤掉枪声、无人机或 Boss 破防声。六个 8 秒、22,050Hz、16 位单声道循环只缓存一份，PCM 合计 2,116,800 字节。暂停与恢复丢弃旧战斗声音，背景重新淡入，不补播离开期间的事件。

## 验证结果

Java 17.0.12、Gradle 8.13、IntelliJ IC 2023.2.2。**83 个测试套件、498 项测试，0 失败、0 错误、0 跳过**，比上个双语批次增加 14 项。`build`、`buildPlugin`、`verifyPlugin` 均通过，正式构建 **1 分 23 秒**。日志：`build/audio-verification/isolated-package.log`。

新增检查覆盖：默认静音不构造设备、菜单中解除静音仍不打开设备、阻塞设备不会阻塞游戏命令、背景和音效共同淡出、背景设 0 后音效仍可用、六循环差异/接缝/DC/峰值、交叉淡化、不占用战斗声部、五关与 Boss 映射、真实面板按键/失焦/隐藏/异常处理，以及 IntelliJ XML 的缺失值与明确解除静音保存。

验证中修复了一个实际时序缺口：设备刚变为可写时，音频线程可能仍持有暂停前的状态。现在入队事件消费前及提交 PCM 前都会核对状态代次；专门用可控栅栏测试该顺序，确保暂停已经发生时旧枪声不会开始播放。

新增设置与战斗底栏提示同步支持中英文，两份资源各 510 条。设置页调整为十行，语言仍在最后一行。`LanguagePreview` 从实际面板导出 **68 张画面**，覆盖两种语言、960×600 与 600×400；新增背景音量和静音说明选中态。`scripts/verify-languages.py` 全部通过，检查了最终绘制文字的语言混用与遗漏。保留的[八张设置图与完整文字](images/2026-09-11-quiet-audio/README.md)用于复查；这些是 headless 面板证据。

使用生产混音器另导出六段 16.5 秒 WAV（两个循环及导出尾部淡出），验证了格式、时长和文件哈希，未自动播放。可以按需手动试听：[工业区](../../build/audio-preview/foundry.wav)、[内存区](../../build/audio-preview/heap.wav)、[蓝图城](../../build/audio-preview/blueprint.wav)、[内核](../../build/audio-preview/kernel.wav)、[奇点](../../build/audio-preview/singularity.wav)、[Boss](../../build/audio-preview/boss.wav)。文件清单为 `build/audio-verification/audio-samples.json`。本轮没有真实设备听感或正在运行的 IDE 内试听，音量平衡仍需结合实际扬声器/耳机确认。
