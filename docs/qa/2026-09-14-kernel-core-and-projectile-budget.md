## 第四关

- 三个断电站位于路线 720 / 2760 / 4780，附近地面按 E 可切断对应轨道 600 tick（9.6 秒）。首次操作分别获得 250 分、15 经验；再次断电不重复领奖。路线有永久存在的 95px 高检修平台。
- 地面轨道的安全、预警、通电范围均由实际控制器状态绘制。通电前完整预警 75 tick（1.2 秒），通电持续 90 tick（1.44 秒），每次伤害 8，伤害间隔 60 tick。最多显示两段轨道；断电站整个交互范围保留安全空间，离屏重新进入后重新预警。
- 首领竞技场有两处故障节点。按 E 武装 450 tick（7.2 秒），然后移到节点另一侧诱导地面冲锋。只有真实冲锋碰到节点才触发故障；普通接触、射击和走路不触发。
- 故障触发时清除竞技场敌弹，实际首领停止攻击和接触伤害 150 tick（2.4 秒），核心受到 1.5 倍伤害；节点进入 600 tick 冷却。故障节点没有可反复领取的分数或经验。
- 冲锋方向在预警开始时锁定，完整预警 60 tick（0.96 秒），起跳后不会临时追踪玩家改变高度。冲锋路径为实际机体覆盖区域；末次位移仍参与扫掠碰撞，避免刚好跨过节点而漏判。两处节点均可触发第一阶段冲锋。
- 首领射击通道在发射前预警 75 tick，提示线与真实弹丸起点、速度一致。转阶段暂停首领新攻击与接触伤害 90 tick，不再立即生成转阶段弹幕；已有可见轨道危险仍按自己的倒计时运行。破防结束及复活后回位不造成接触伤害。
- 新机械 Interrupt 与重型执行机使用预缓存分层机体，表现蓄势、冲锋、受击和装甲打开；场景加入涡轮机、变压器、供电桥架、实体线缆与检修平台。沿用既定工业机械美术方向。
- 新剧情随路段、实际断电、节点武装、故障触发和首领阶段推进。中英文目录同步，默认静音与原有音频设置保持生效。

Continue 仍恢复关卡入口，不保存任意战斗帧。复活清除临时危险与武装状态，保留本次关卡的已领奖标记和节点冷却；暂停及升级选择冻结机制。五世界原有安全首领入场流程继续使用。

## 弹丸生成前准入

生产玩家弹丸容量 320、敌弹容量 180 保持原值，超额时原子拒绝新的一整束射击，保留已经存在的弹丸。拒绝发生在构造弹丸和消耗战斗随机数之前。玩家未成功发射时不消耗弹药、冷却、热量爆发、冲刺强化和发射音效；蓄满的射线等待容量可用。

敌方首领每组齐射原子准入；容量不足时该组不发射，攻击时序继续，不补发积压弹幕。普通射手保留最后一帧预警并等待空位。无人机沿用生成前容量与独立冷却，反射在有空位后才消耗反射次数。拒绝弹丸数与齐射数可观察；清屏保留诊断计数，新关卡/恢复重置诊断区间。

`ProjectileBuffer` 保持 List 索引、迭代器和子列表契约，普通越界插入会报错；生产路径通过 `ProjectileBudget` 正常拒绝，不靠删除已在场弹丸来追赶上限。粒子和浮字仍按既有装饰数量上限裁剪。

- 构建前后 268 个源文件哈希一致；包内 26 个关键类均存在，14 项图片、元数据与语言资源与源码逐字节一致。之后仅修正性能探针的采样时长说明文字（实际一直为 1750ms），不改变生产代码或测量过程；修正后使用 Java 17 单独编译通过。补充调用 `compileTestJava` 时遇到 IntelliJ Gradle 插件 `classpathIndexCleanup` 的任务依赖校验错误，因此改用隔离目录的 `javac` 验证这一处元数据修正；此前完整构建、测试和包验证均已成功。

性能使用同一个 `KernelPerformanceProbe` 对上个验证 ZIP 与本批正式编译输出做对照，覆盖第二/第四世界、普通/满预算场景和 600×400 / 960×600 / 1280×800。每场景预热 750ms、采样 1750ms；测量真实 GameLoop → GamePanel 更新/发布与 EDT paint，人工负载补充不计入单步耗时。原始帧数量与实体数量保留在 CSV。原始日志曾误写采样 2000ms，实际常量与三个版本的测量过程均为 1750ms。

这属于 headless Java2D 调用耗时，不是实际 IDE 帧率；顺序短采样受预热和机器负载影响。新增危险提示不随低特效关闭。真实 IDE 中的输入延迟、HiDPI、30 分钟内存/线程稳定性及真人数值平衡仍需单独验收。

完整原始 CSV、数量分布、内存/线程摘要和哈希已保存在 [性能证据目录](data/2026-09-14-kernel-performance/README.md)。旧包、未缓存初稿、最终缓存版分别采集 1546 / 1286 / 1352 帧，全部发布成功。普通负载每步注入 6 敌人 / 32 玩家弹 / 12 敌弹 / 120 粒子；更新后真实刷怪、射击偶尔使第四关敌人变为 7、敌弹变为 13。全部满预算样本均严格保持 40 / 320 / 180 / 1200。
