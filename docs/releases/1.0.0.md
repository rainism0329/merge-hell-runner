# Merge Hell Runner 1.0.0 — Campaign Release

The build is red, the deadline is tonight, and Merge Hell Runner is ready for its
first stable release.

Version 1.0.0 turns the original runner into a complete five-mission campaign. Every
chapter now has its own visual identity, enemy ecosystem, route pacing, arenas, and
boss encounter.

## Highlights

- Explore Repository City, Heap District, Blueprint Citadel, Kernel Core, and
  Singularity Edge—five worlds with genuinely different scenery and atmosphere.
- Fight five handcrafted bosses. Later encounters no longer share one generic pattern:
  Memory Leak controls the heap, The Architect constructs attack grids, Kernel Panic
  weaponizes ring-0 interrupts, and Singularity learns from every fight before it.
- Meet four new enemy families—Leak, Sentinel, Interrupt, and Mirror—mixed into unique
  per-level rosters and arena formations.
- Build a run with six weapons, upgrades, dash i-frames, double jump, melee, bombs,
  shields, health drops, combo scoring, coins, and a persistent local leaderboard.
- Use Lab Mode (`F12`/`T`) to inspect encounters quickly. Lab actions are deliberately
  marked unranked so testing cannot affect leaderboard results.

## Stability fixes

- Cleared arenas no longer restart in an endless loop.
- `F11`/`L` now reaches the boss correctly in every mission.
- Mission-complete cards stay on screen long enough to read and fade cleanly.
- Boss warning, pause, mission-number, and HUD transition state are synchronized with
  the main game loop.

## Compatibility

- IntelliJ IDEA 2023.2 or newer (`since-build 232`).
- Java 17 runtime/toolchain.
- Plugin ID: `com.bigphil.mergehell`.

## Installation

Download `merge-hell-runner-1.0.0.zip`, then open IntelliJ IDEA and select:

`Settings` → `Plugins` → gear icon → `Install Plugin from Disk…`

Select the ZIP directly; do not extract it. Restart the IDE if requested.

The accompanying `.sha256` file can be used to verify the download before installing.

See the [v1.0.0 changelog](https://github.com/rainism0329/merge-hell-runner/blob/v1.0.0/CHANGELOG.md)
for the complete change list.
