## Before publishing

- Confirm that version 2.0.0 has not already been uploaded to Marketplace.
- Install the candidate ZIP in the supported IDEs and smoke-test gameplay, Continue, language selection and audio.
- Stage the final additions and deletions, commit the release changes, and verify that tag `v2.0.0` points to that commit.
- Publish, check the uploaded archive/version, then announce the release.

Pushing a version tag triggers the existing GitHub Release workflow and also publishes to
Marketplace when all required credentials are configured. Details: [RELEASING.md](../../RELEASING.md).

The minimum declared IDE build remains 232. Local package verification does not establish
compatibility with every later IDE version. A CI rebuild or signed archive has its own checksum.
